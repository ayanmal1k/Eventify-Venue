This folder should contain the following image files:
- icon.png (1024x1024 - App icon)
- adaptive-icon.png (1024x1024 - Android adaptive icon)
- splash.png (1284x2778 - Splash screen)
- favicon.png (48x48 - Web favicon)

For now, you can use placeholder images or create your own with a purple theme.
To generate these quickly, you can use online tools or simply colored squares with the purple gradient (#5B21B6).
